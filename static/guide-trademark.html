How to file a trademark — overview

Use this path to protect a brand — name, logo, or slogan you use in commerce. A trademark is not a patent. If you invented a product, start with the patent guide as well.

The path

  1. Pick a strong mark (distinctive, not a generic product name).
  2. Clearance search — USPTO Trademark Search plus common-law uses (web, state filings). Filing without a search is how conflicts start.
  3. Identify goods and services and how the mark is already used, or will be used, in commerce.
  4. File on USPTO TEAS with the right specimens and fees.
  5. Watch the application — office actions, publication, then maintenance after registration.

Stop and talk to an attorney if…

  • Search shows a similar mark in your class, or you received a cease-and-desist.
  • You are expanding nationwide or licensing the brand.
  • The USPTO issued an office action you do not understand.
