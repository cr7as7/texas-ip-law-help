2. What actually drives “accurate” answers

Brand name alone does not make inventor answers reliable. For IP education (not legal advice), quality comes from how you deploy the model:

  • Curated knowledge — your guides, approved FAQs, blog excerpts, USPTO URLs injected into each request (RAG).
  • System instructions — “educational only,” cite USPTO, link to your guides, escalate to consultation, never claim attorney-client relationship.
  • Model tier — “mini / Flash / Flash-Lite” for most questions; optionally route hard questions to a stronger model.
  • Optional web grounding — Google Search grounding on Gemini (~1,500 free/day, then ~$35/1,000 queries) or similar; use sparingly with a cap.
  • Fallback when budget hits — knowledge-base answers only ($0 API) so the site never “goes dark.”

With that stack, GPT-4o mini, Gemini Flash, or Grok 4.3 can all feel close to what you see in the apps — often better for your site because answers are grounded in your content and disclaimers.

Important: No model guarantees legal accuracy. The product is general education + links to official sources + path to Texas IP Law Group for advice on specific facts.

An inventor types a question in Ask AI. The site either:
(A) Free reply — answer from your guides / FAQ library — $0 API (about 55% of replies).
(B) Paid reply — ChatGPT / Gemini / Grok API writes the answer — uses tokens (about 45% of replies).

1 million API tokens ≈ only the (B) replies: about 280 paid AI answers (each ≈ 3,000 + 600 tokens with your content included).

6. Recommended architecture (accuracy + predictable bill)

Recommended for texasiplawhelp.com:
Primary: OpenAI GPT-4o mini or Google Gemini 2.5 Flash-Lite for almost all chats (low cost, app-like quality).
Optional: auto-escalate ~5–10% of turns to GPT-4o or Gemini 2.5 Pro when the user asks a multi-step patent/strategy question.
If the site uses Grok API: Grok 4.3 as primary (not 4.7 on every reply).
Hard cap: $25–50/month in WordPress admin → then knowledge base only until next month.

Cost controls (same for any vendor)

  • Monthly spend cap — e.g. $25 (your earlier planning number); API stops, KB continues.
  • Daily token limit — e.g. 400k tokens/day.
  • Per visitor session — e.g. 6–8 AI replies, then “schedule consultation.”
  • Match FAQs first — provisional vs non-provisional, trademark basics → no API call when confidence is high.

7. Other website line items (beside §5)

  • Optional Gemini Google Search grounding on the site: $0 at low volume; $10–35/mo if many grounded searches
  • Hosting / domain (texasiplawhelp.com): unchanged — separate from API
  • Worst case any month = Website API cap in §5 (e.g. $50); typical bill = Website API bill (est.) column
